Important Login Instructions

App and super login only token se hi kare. Hamara token server maintenance par hai, isliye aapse request hai ki minimum 2 ya jitne aap easily tokens generate kar sakte hain, utne tokens generate karke hi login karein.

Steps for Token:

APK me apna Tesla ID dal kar Token Post karein.

Fir Tesla me Check Token me jaakar apna token get karein.

Token get karne ke baad ek popup aayega:

No ? agar aap wahi token use karna chahte hain.

Yes ? agar aap aur tokens add karna chahte hain.
Dhyan rahe, Yes tabhi kare jab aapne aur token post kar dia hai.

Token show hone ke baad hi Open Ticket karein.

Web Login ke liye:

Auto Update disable karein.

Fir login karein aur diye gaye steps follow karein.
