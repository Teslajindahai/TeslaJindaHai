Token Get karne ke 2 tareeke:
Normal APK (jo aap abhi use kar rahe ho)===> Agar Apka sab sahi work kar raha hai to dusre APK par na jaye.
Dusra APK (jo “Get Token” form me link se download karna hoga)
Agar aap Dusra APK use karna chahte ho:
Pehle jo purana APK install kiya hai, use uninstall kar do.
Naya APK install karo (jo Get Token link se milega).
APK open karo aur apni TESLAX ID enter karo.
Jab status “Connected” show ho jaye to fir apne pairs login karo.
Sare PAIRS setup kar lo Tab APK open kare aur connect kare then login kar de.
Important Settings (use karne se pehle):
Display Timeout: Maximum kar do (taaki screen auto-off na ho aur connection band na ho).
Battery Optimization: App Info me jaake battery optimization ko Unrestrict kar do.
Connection ka Dhyan:
Connect tabhi kare jab saare pairs login ke liye ready ho.
Har 1 minute me APK auto disconnect aur reconnect karega.
Agar status “Connected” dikh raha hai to hi Tesla me token generate hoga.Warna wo auto pichle generated token use karega.
Jab tak booking complete na ho jaye apk ko open aur connected rakhe.
